# Тестовое Neowise. AI-помощник для входящих заявок

Ориентир — 45–60 минут. Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через `PORT`.

## Тесты

```sh
node test.mjs
```

Проверяет пустой ввод (`invalid_input`), таймаут / плохую тему / пустой черновик (`manual_review`) и успешный разбор.

## Что сделано

1. `POST /api/triage` — валидация `text`, таймаут модели 300 мс, допустимые темы `delivery|pricing|other`, непустой draft; иначе `manual_review`.
2. UI — тема и черновик при успехе; при сбое сообщение про ручной разбор и очистка предыдущего черновика.
3. Имитатор `mock-ai.mjs` не менялся.

## Для описания PR

- Результат AI проверяется на сервере: JSON, тема из whitelist, `draft.trim()` не пустой; ожидание модели ограничено 300 мс.
- При сбое API отдаёт `manual_review` с `topic/draft = null`, UI чистит старый черновик и просит разобрать вручную.
- AI при выполнении: Cursor. Самостоятельно проверил `node test.mjs` и сценарии `[timeout]`, `[bad-topic]`, `[empty-draft]`, пустой ввод в UI.
- Польза для менеджера: быстрее первичная сортировка заявок; метрика — время на заявку и доля без ручной правки.
